Modbus has to be asked, so this one polls. Five times a second is nothing on the wire.

Contacts bounce, and a float bobs on the water, so a reading has to hold this long before it counts. Without it one call for water is recorded as a dozen. Applies to all eight inputs.

What each input is wired to

Name an input and it is watched. Leave it blank and it is ignored. Name them after what the panel calls them.

On when is which way round the wire works. Most contacts send voltage when the thing happens. Alarm and overload contacts are often the other way, holding voltage while healthy so a cut wire reads as a fault. Set backwards, an alarm reads as on forever and goes quiet when it matters, so check each one with the live view below.

Timing

A motor pulls six to eight times its running current as it comes up to speed. Readings in this window are left out of the averages and the overcurrent check. The peak is still recorded.

A stuck float, or pumping against a blockage. If a normal run is three or four seconds, ten is well outside it.

Silence can be a dry spell, or a stuck float, a clamp that has fallen off, or a dead panel. Set it a bit longer than the longest normal gap.

Short cycling

A check valve that stops sealing lets the discharge pipe run back into the pit the moment a pump stops, which calls it straight back out. Measured between runs of either pump, so alternating does not hide it.

Off unless you set a gap, and fine left off. Counted by how soon rather than how often, because a pit taking roof water cycles all through a storm.
