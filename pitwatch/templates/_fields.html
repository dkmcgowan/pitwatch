Topics

Where the module publishes all eight inputs together. Every message carries the whole state, so nothing is assembled from fragments and a message lost on a reconnect cannot leave this quietly wrong.

The module says online here when it connects, and the broker says offline on its behalf when it stops. A module that loses power announces it rather than being noticed missing after a timeout.

Contacts bounce, and a float bobs on the water, so a change has to last this long before it counts. Applies to all eight inputs.

What each input is wired to

Name an input and it is watched. Leave it blank and it is ignored. Name them after what the panel calls them.

On when is which way round the wire works. Most contacts send voltage when the thing happens. Alarm and overload contacts are often the other way, holding voltage while healthy so a cut wire reads as a fault. Set backwards, an alarm reads as on forever and goes quiet when it matters, so check each one with the live view below.
