{% endmacro %} {% macro waveshare_fields(waveshare, signals) %}

Modbus has to be asked, so this one is a poll. Five times a second is nothing on the wire and it is the difference between catching a short lag float call and missing it.

What each input is wired to

Each signal belongs to one input, so picking it on one channel takes it out of the others. Set a channel back to Not connected to free its signal up again.

Invert is the setting that is easiest to get wrong and worst to get wrong. Tick it when the input reads the opposite of the signal: a dry contact wired normally closed, or a live line that holds voltage while all is well and drops it on the fault. Alarm and overload contacts are often built that way on purpose, so that a cut wire reads as a fault rather than as silence. Set it backwards and the alarm reads as on forever, then goes quiet at exactly the moment it matters. Use the live view below to check each one against the panel rather than guessing.

An ejector pump runs for a few seconds at a time, so the timings here are in milliseconds. Seconds are too coarse a unit to describe anything that happens inside a run that short.

Pump {{ number }}

Not zero. A clamp on a live conductor reads a little noise with the motor off.

The number printed on the motor itself, often as FLA: what it draws doing the work it was built for. Nothing is calculated from it. It is here so the threshold below can be judged against something real, and so a pump drawing more than its own rating is obvious.

Set this just above what the pump normally draws once it is turning. The starting surge is thrown away before this is checked, so a motor that spikes to 60 A and settles at 16 A will not trip a threshold of 18 A. Leave empty to skip the check.

How long it has to stay above that before it counts, measured after the start has been discarded. This plus the ignore window below has to fit inside a normal run or the alert can never fire.

{% endfor %}

Timing

A motor pulls six to eight times its running current for a fraction of a second as it comes up to speed. Sixty or seventy amps settling to sixteen is a healthy pump, not an overloaded one. Every reading inside this window is left out of the run's averages and out of the overcurrent check above, which is what lets that threshold sit just above the running current. The peak is still recorded separately, because a starting surge that climbs month over month is a bearing on its way out.

How long the current has to stay down before the run is treated as over. Long enough to bridge a momentary dip, which would otherwise split one run into two; short enough that two real runs a few seconds apart are still counted as two.

A stuck float, or pumping against a blockage. If a normal run is three or four seconds, ten is already well outside it.

Short cycling. The pumps starting far more often than the building can be filling the pit. Usually a check valve that has stopped sealing, so each time a pump stops, what it just pushed up the discharge pipe runs straight back down and calls it out again. It wears the motors out and it is invisible unless something counts the starts.

The opposite problem. Silence can mean a genuinely dry spell, or it can mean the float is stuck down, the clamp has fallen off, or the panel is dead and nothing is watching the pit at all. Set it to a bit longer than the longest gap you would expect to see normally.
