Calls for water

A call is one filling of the pit: the floats rose, one or both pumps ran, the pit emptied. Two pumps answering one call is one call, which is why this is not the same as a count of runs.

Counted from the panel's run contacts, so it is exact rather than a floor. A call that took both pumps, or that reached the high float, is marked on top of its bar.

This is the number that moves when it rains.

Time between calls

One dot per call, placed at how long it had been since the call before it. The dashed line is the middle of the window.

Dots falling toward the floor mean the pit is filling faster: rain, a check valve that is not holding, or something upstream running that usually is not. A single low dot is normal; a run of them is not.

How long each run lasted

One dot per run, from the moment the panel closed the run contact to the moment it opened it. The dashed line is the middle of the window for that pump.

A pump that starts taking twenty seconds where it used to take twelve is moving less water per second: a worn impeller, a partly blocked line, or a check valve letting water back down. It shows here before it shows in the current.

This works on a pump with no clamp fitted, which is the point.

{# What the motor drew while it ran. Only for a clamp that has proved it can see current: a channel with no CT reads a convincing zero. #}

What each run drew

No clamp has read current yet. The current transformers are per pump, and a channel without one reads zero.

What each run drew

The dot is the steady current: the median of the readings taken while the contact was closed, with the first one dropped. A motor draws several times its running current for the moment it starts, and leaving that in would make every run look the same.

The line above each dot reaches to the peak, starting surge and all. A surge climbing month over month is a motor with a problem, and it is usually the first place it shows.

A pump whose clamp has never read current is left out rather than drawn along the floor. Zero from a channel with no CT on it is not a measurement.

Time of day

Every run in the window folded into a single day, by the hour, in this building's own time.

It says where the water is coming from. A pit that runs evenly around the clock is taking groundwater. One that doubles between eight and one is taking the building's, which means the pattern will follow the people in it rather than the weather.
